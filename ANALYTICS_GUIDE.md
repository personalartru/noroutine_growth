# Графики динамики просмотров: аналитика по каналам (Telegram + MAX)

## Что реализовано

### 📊 Сбор данных
- **`fetch_analytics.py`** – единый скрипт для парсинга обоих каналов:
    - Telegram: просмотры постов и подписчики с пагинацией (102 поста на канале)
    - MAX: просмотры через MAX Bot API (`stat.views`) и подписчики (`GET /chats`)
- Формат данных: `analytics.json` с историей по дням (последние 120 дней), суммарными просмотрами, подписчиками, списком постов

### ⚙️ Автоматизация
- **Workflow `sync-analytics.yml`** в `noroutine_growth`
    - Запускается **каждые 6 часов** и при ручном запуске
    - Устанавливает Python, собирает аналитику, коммитит JSON в `noroutine_posting`
- **Кеширование**: история сохраняется, добавление новой записи за текущий день

### 🖥️ Админка `index.html`
- Добавлен блок **«Аналитика по каналам»** после статистики
- Графики Chart.js:
    1. **Линейный график** – новые просмотры по дням (Telegram vs MAX)
    2. **Гистограмма** – суммарные просмотры за 14 дней (сравнение)
    3. **Топ посты** – горизонтальная гистограмма топ-12 постов Telegram по просмотрам
- **Виджеты** для каждого канала: суммарные просмотры + подписчики
- **Статус-бар** – обновлено вручную или автоматически

### 📈 Интеграция с существующей админкой
- Виджет «Суммарно просмотров» показывает **сумму по обоим каналам**
- При наведении – тултип с разбивкой по каналам
- Аналитика загружается асинхронно, не блокирует интерфейс

## Как запустить в первый раз

1. **Получить MAX Bot Token** с правами на чтение канала и добавьте в секреты репозитория `noroutine_growth`:
    ```
    MAX_BOT_TOKEN: <ваш токен>
    ```

2. **Включить workflow** – будет активирован по расписанию (каждые 6 часов)

3. **Ручной запуск** аналитики:
    ```bash
    gh workflow run sync-analytics.yml --repo personalartru/noroutine_growth
    ```

4. **Открыть админку**: https://personalartru.github.io/noroutine_posting/
    - Настройте GitHub PAT (токен) в разделе ⚙️ Настройки GitHub
    - Нажмите кнопку обновления 🔄 в блоке аналитики

## Поддерживаемые каналы и метрики

| Канал | Просмотры | Подписчики | Лайки |
|-------|-----------|------------|-------|
| Telegram | ✅ парсинг со страницы | ✅ из `tgme_channel_info_counter` | ❌ недоступно |
| MAX | ✅ `stat.views` | ✅ `subscribers_count`/`members_count` | ❌ API не даёт |

## Ограничения и расширения

### Сейчас
- **Telegram**: парсинг только публичного канала (требуется доступ в интернет)
- **MAX**: нужен токен бота с правами чтения
- История обновляется раз в 6 часов (GitHub Actions limitation)

### Потенциальные улучшения
- График подписчиков по дням (с накоплением)
- Сравнение средних просмотров
- Сегментация по тегам (например, #автоматизация vs #менеджмент)
- Автогенерация отчётов в Telegram-админку

## Проблемы

- Если графики не отображаются – проверьте, что `analytics.json` доступен по `https://raw.githubusercontent.com/...`
- При отсутствии MAX-токена блок MAX будет пустым, Telegram – заполнится
- Для обновления в реальном времени можно установить Webhook, но это требует сервера
