# Закреплённый пост канала @noroutine2026

Текст для закрепления. Публикуется скриптом `publish_pinned.py` (ветка
`feat/pinned-post` в репозитории `noroutine_posting`) — бот отправляет его в
канал и закрепляет через `pinChatMessage`.

Плейсхолдер `<BOT_USERNAME>` подставляется из переменной окружения
`BOT_USERNAME` (юзернейм бота, который выдаёт лид-магнит).

## Почему такой текст

| Элемент | Зачем |
|---|---|
| Кто вы + о чём канал | первые 3 секунды: это для меня или нет |
| Список из 3 блоков | конкретика вместо обещаний, видно ценность |
| Цифры экономии | у вас есть 100+ процессов и 450+ часов/мес — это и есть доказательство |
| Лид-магнит с прямой ссылкой | причина подписаться прямо сейчас |
| Ссылка на сайт | конвертирует тёплых в заявки |
| Призыв «напишите» | лид-магнит в Telegram → заявка на внедрение |

## Что проверить перед публикацией

1. `<BOT_USERNAME>` заменён на реальный юзернейм бота.
2. Кнопка-ссылка в сообщении кликается (если публикуете через `sendMessage`,
   добавьте `reply_markup` с кнопкой — текст с обычной ссылкой тоже работает).
3. Бот — администратор канала с правом «Закрепление сообщений».
4. Пост закреплён, а не просто опубликован: в Telegram это видно по «📌».
