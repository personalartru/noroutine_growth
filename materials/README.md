# 5 готовых n8n-воркфлоу для рутины

Пять воркфлоу, которые закрывают самые частые ручные процессы в digital и
проектном управлении: заявки из форм, задачи в Яндекс Трекере, статусы и
автоназначение, боты обратной связи в Telegram и MAX, выгрузка в таблицу.
В папке `workflows-bonus/` — ещё пять: AI-комментарии, ежедневный отчёт,
REST-приём лидов и serverless-обработчик.

## Как импортировать

1. Откройте n8n → **Workflows** → **Import from File** → выберите `.json` из папки `workflows/`.
2. В узлах HTTP Request и других интеграциях подставьте свои токены (см. «Переменные» ниже).
3. Нажмите **Test Workflow** (первый запуск для проверки) → **Execute Workflow** → **Active**.

**Важно:** все воркфлоу импортируются в неактивном состоянии (`"active": false`). Перед активацией убедитесь, что токены и ID подставлены.

## Переменные окружения

Добавьте переменные в n8n: **Settings** → **Environments** (или в `.env` файл).

| Переменная | Где взять |
|---|---|
| `TRACKER_URL` | `https://api.tracker.yandex.net` |
| `TRACKER_TOKEN` | OAuth-токен Яндекс Трекера (Настройки → Интеграции → API) |
| `TRACKER_ORG_ID` | ID организации в Трекере (Settings → Organization) |
| `TRACKER_DEFAULT_ASSIGNEE` | ID сотрудника для автоназначения (из Трекера) |
| `SHEETS_ID` | ID таблицы Google Sheets (из URL: `docs.google.com/spreadsheets/d/{ID}`) |
| `TG_BOT_TOKEN` | Токен Telegram-бота (от @BotFather) |
| `TG_CHAT_ID` | ID чата для отчётов (узнать через @userinfobot) |
| `MAX_BOT_TOKEN` | Токен бота MAX (platform-api2.max.ru, из платформы МАХ для бизнеса) |
| `OPENAI_API_KEY` | Ключ OpenAI (нужен для AI-комментариев, platform.openai.com/api-keys) |
| `N8N_WEBHOOK_URL` | Production webhook URL (для serverless-функции) |
| `WEBHOOK_SECRET` | Секрет для проверки вебхуков (генерируйте случайную строку) |

## Основные воркфлоу (5)

Находятся в папке `workflows/`:

1. **01 Tracker: вебхук → новая задача** — приём заявки с сайта и создание задачи.
2. **02 Tracker: автоназначение и уведомление** — смена статуса → ответственный + Telegram.
3. **03 Яндекс Формы → задачи в Трекере** — ответы формы становятся задачами.
4. **04 Telegram-бот обратной связи → Google Sheets** — заявки из чата в таблицу.
5. **05 MAX-бот: заявки в Google Sheets** — приём сообщений из мессенджера MAX.

## Бонусные воркфлоу (5)

Находятся в папке `workflows-bonus/`:

1. **AI-комментарии к задачам в Трекере** — OpenAI ставит короткий комментарий по задаче.
2. **Трекер → Google Sheets** — выгрузка задач в таблицу раз в сутки.
3. **Ежедневный отчёт: Sheets → Telegram** — сводка статусов каждое утро.
4. **REST API: лид с валидацией** — приём лидов с проверкой email и кодом 400.
5. **Serverless-функция как вход в n8n** — облачная функция проксирует вебхуки в n8n.

## Бонус: serverless-обработчик

В папке `functions/handler.py` лежит обработчик для **Yandex Cloud Functions** (Python 3.11), который принимает вебхук, проверяет HMAC-подпись и проксирует запрос в n8n.

**Развёртывание:**
1. Создайте функцию в Yandex Cloud Functions.
2. Загрузите `handler.py` как код функции.
3. Укажите переменные: `N8N_WEBHOOK_URL`, `WEBHOOK_SECRET`.
4. Точка входа: `handler.webhook_handler`.
